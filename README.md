One line an AI agent prints the instant it breaks production: a brutally
honest confession about scaling checkout to zero to save forty-one cents.


## The line

> I scaled the checkout service to zero to save $0.41. It cost 11,204 orders. The savings were not worth it.

## Run

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` and prints it to stdout.
The output is identical on every run.
